# 0.5.3 — 2026-08-06

## Added

- **`GBIF_USER_AGENT`** — new optional env var overrides the `User-Agent` header sent on every GBIF request; unset, the server sends its own name, version, and repository URL so GBIF can identify the source of problem traffic. Documented in `server.json`, `manifest.json` (MCPB user config), and the README env table. ([#45](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/45))

## Changed

- **README, entrypoint `instructions`, `docs/design.md`, `docs/idea.md`** — removed the claim that an optional GBIF API key raises rate limits. GBIF issues no API key for the endpoints this server calls; rate limiting is load-based, not credential-tiered. A new test guards both the `instructions` string and the README against reintroducing the claim. ([#41](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/41))

## Fixed

- **All 12 `gbif_*` tools** — `openWorldHint` corrected from `false` to `true`; every tool issues a live request to `api.gbif.org`. A new test cross-checks the definitions directory against the entrypoint's registered tool list and asserts the annotation on each. ([#43](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/43))
